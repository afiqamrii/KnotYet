# Live QA and Number Guesser readjustment

## Changes

- Number Guesser uses a compact cream play panel, lavender range indicator, prominent input/submit controls, and a wider clue history. The panels size to their content instead of stretching into empty space. Phones stack history below the controls; short laptops use tighter spacing.
- Secret Number Race uses a compact two-column desktop card, labeled scoreboard, round progress, and an input panel beside the instructions. Phone layouts stack the controls. Subtraction has an accessible sign toggle for numeric keyboards; countdown, locked-pick, answer, and result states use the same restrained style.
- Same-account auth refreshes update profile data without unmounting the protected game route and its multiplayer provider. Account changes still clear the previous account's session.
- Peer signaling and data-channel setup have a 15-second deadline. Restored rooms retry temporary host-ID conflicts and stalled joins. A signaling reconnect preserves a healthy data channel.
- Leaving or cancelling a room clears shared-round snapshots and returns to a fresh game introduction. Local Memory and Story progress stays separate.
- Automatic desktop chat docking collapses on a narrow viewport. Explicit open/minimize choices and drafts are preserved. The session clock hides below 360px so primary header controls fit.
- Room guidance no longer advertises an unenforced daily limit.
- Desktop Icebreaker Cards retain their answer/reveal controls, including riddle entry on short laptops.
- Same-account multiplayer applies each reward or deduction once through the host. Account changes/sign-out clear room restoration keys and private round snapshots; background refreshes preserve them.
- Secret Number Race requests/replays missed setup state and offers a bounded retry. Validated room/role snapshots restore private locked picks, scores, deadlines, and reward markers after refresh without publishing picks before GO.
